## 兑换入口的交付边界

- 公共商品说明仅介绍选规格、付款确认、订单领码与自行兑换的流程，不包含兑换地址。
- 完整入口及分步教程由 `worker/xiaojiu/redemption-copy.ts` 维护，使用现有商品凭据加密机制写入 `shop_redemption_guides`，与公开商品 JSON 分开。
- 新订单保存加密的指引快照，避免后续编辑改变既有订单的兑换去向。
- 只有真实模式、非测试、服务端确认到账且订单成功交付非空内容时，才向有权访问该订单的买家返回指引。未付款、仅声明付款、处理中、交付失败、退款或限制兑换状态不返回。
- 前台订单提供交付内容复制及安全的兑换链接。原订单的历史公开备注也经过地址清理，不会因旧快照而在付款前泄露入口。
- 通用付款回调产生的已付款订单可继续进入商品交付；本次只使用模拟支付结果和采购响应验证，不启用线上收款或真实采购。

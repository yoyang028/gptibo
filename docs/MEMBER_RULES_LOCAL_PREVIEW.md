# 会员中心活动规则融合：仅本地预览

2026-11-15，按用户要求在现有会员中心融合已确认的活动设计。本轮未执行部署，没有数据库、密钥、生产配置或采购路径改动。

顶部邀请横幅突出 10 元购物奖励及好友可选 5 元优惠；会员登录后，专属邀请链接放在奖励数据之前。游客点击邀请按钮仍定位邮箱表单，会员点击仍复制原邀请地址，冻结账号保持禁用。

底部展示三步参与说明及新客条件，完整规则默认折叠。顶部规则链接可直接展开、定位并聚焦规则入口，原生详情控件保留键盘操作。文案补齐新客核验、真实实付交付、24 小时观察期、两个自然月有效期、优惠互斥、余额保留、人工审核、低价／零元待处理及取消退款恢复；所有业务计算沿用既有实现。

构建、TypeScript 和 19 组真实本地 workerd/D1 浏览器验收通过，覆盖访客注册、链接复制及自定义、手机首屏、规则定位和键盘折叠，以及既有优惠、付款交付模拟和管理流程。静态检查无错误，保留 6 项既有警告。

本地预览使用独立模拟账号、邮件、上游及数据库。演示脚本、运行数据和浏览器证据均位于 Git 忽略目录，不进入提交或部署。现网版本仍以上次 [发布记录](MEMBER_EXPERIENCE.md) 为准。

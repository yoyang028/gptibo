# 商品展示样式

适用于当前 Cloudflare Workers / D1 商城。主后台「商品与套餐 → 展示样式」管理现有商品和自营商品；「我的店铺 → 商品发布」的每条商品也有同名入口。样式按商品保存，同一商品下的套餐共用展示，不改变套餐名称、售价、上下架或交付方式。

上传 5 MB 以内的 PNG/JPG，选择模板即可实时预览，并可切换电脑/手机预览尺寸。上传后在浏览器本机执行以下处理，不调用 AI 或其他图片服务：

1. 检测图片外围是否为一致的简单背景，只清理从边缘连通的背景区域；封闭在主体内的白色符号、颜色和渐变不参与全局去色。照片或复杂背景不明确时保留原色。
2. 清理符合简单颜色混合条件的邻接杂边和远离主体的极小孤立杂点，裁剪透明留白并保留安全边距。裁剪后主体自然占满展示区域，不拉伸比例。
3. 保留处理前副本，可对比、重新处理、还原原图及撤销最近 20 步编辑；背景清理、强度、裁剪和杂边处理都能单独调整。原始文件不会修改。

图片最长边最多 1024 像素；每份保存图片的 data URL 上限 600 KB，超过时逐级缩小。透明素材保存为 PNG，内部 RGB 与透明度保留；未清理的照片可保留高质量 JPG。编辑副本不含原文件的 EXIF 等元数据，公开目录只发送处理后的展示图，不发送原图副本及处理参数。

可选「尝试矢量化」仅对最多 8 种主要纯色、轮廓复杂度受限的简单 Logo 生成颜色区域轮廓。渐变、照片、半透明或复杂素材保留高质量位图，不强制近似。矢量配置只包含校验后的数字路径和十六进制填色，禁止上传 SVG、脚本或外部引用；位图始终保留，可随时切回。

后台还可调整主体大小、水平/垂直位置、默认柔光/透明/自定义纯色/自定义柔光背景，以及投影/圆台底托和颜色。上传后的裁边先解决主体过小，再按需调整布局。预览和前台列表、详情共用展示组件；保存后重新编辑会保留素材、处理选项、布局、模板及可选矢量配置。旧版本只有图片与模板的配置仍按原默认外观展示。

| 模板 | 展示方式 |
| --- | --- |
| 沿用原展示 | 默认选项，保留现有商品图片、ChatGPT 套餐卡组与原会员动效 |
| 静态 | 展示上传图片，不添加图片动画 |
| 漂浮 | 图片缓慢上下漂浮 |
| 缩放 | 图片缓慢缩放 |
| 扫光 | 图片上叠加周期性柔和扫光 |
| 会员卡片 | 使用商城现有会员场景与卡片样式展示图片、商品名称和规格 |

关闭编辑窗口或切换商品前，会提示处理未保存的修改。选择「沿用原展示」并保存后恢复默认展示，之前上传的图片仍在配置中，可再次选择其他模板。系统开启“减少动态效果”、页面切到后台或展示区域离开屏幕时，动画停止；图片本身仍可正常显示。手机布局与暗色颜色沿用商城现有样式。

展示配置独立保存在 `0047_product_artwork.sql` 创建的 `product_artwork` 表中，包含乐观锁版本及管理员审计。本次扩展 JSON 配置，无需新增数据库迁移。不更新商品业务记录、库存、采购参数、支付与订单状态，不接入 AI。未登录用户不能使用管理接口；公开目录只返回可展示商品的有效配置，不公开未发布自营商品的图片，也不覆盖代理店铺的原有展示。

先应用迁移、构建并启动项目的独立本机 Cloudflare 环境，再运行：

```sh
npm run test:cloudflare:product-artwork
```

脚本固定使用本机 `https://127.0.0.1:8771`，通过模拟邮箱和测试验证器登录。浏览器禁止外部请求和付款、充值写请求；结果与截图保存在被 Git 忽略的 `artifacts/local/evidence/product-artwork/`。测试结束会恢复原本机 ChatGPT 展示，并将自建测试商品下架。

像素测试包含 Codex 类蓝紫渐变、封闭白色符号、杂边、透明留白、复杂背景保留和纯色矢量轮廓；接口测试覆盖新字段保存重开、原图不公开、非法参数/路径拒绝、商品业务数据不变。浏览器脚本覆盖实际上传处理、前后对比、撤销、布局调整、保存重开、前台实际渲染、五种模板、自营商品、390px 手机、减少动态效果、离屏暂停和恢复原动画。没有新增真实支付或供应商交易测试。

2026-10-16 验证：完整 Node 回归 449 项通过；本机 workerd/D1 + Chrome 完整验收 15 项通过，另完成新增素材流程和手机后台的 7 项定向复查（`npm run test:cloudflare:product-artwork -- --materials-only`）。构建、应用及 Worker TypeScript 检查通过；静态检查仅保留原有 5 条 Fast Refresh 警告。像素断言使用确定的 Codex 类测试素材，不把本机模拟数据视为真实商品交付验收。

发布前核对当前部署配置与数据库书签，应用新增迁移。保持现有供货、支付、测试开关及商品映射不变，不向正式库上传测试商品或测试图片。旧版本忽略新表，回退展示功能不需要删除已保存配置或恢复业务数据库。

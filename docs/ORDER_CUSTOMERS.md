# 自营店订单与自动客户档案

后台显示顺序为 ScholAI、AI星球、备用商店。备用商店保持停用。显示顺序放在店铺设置的 `displayOrder`，原店铺 ID、路径、域名、会员关系与历史订单归属不变。

「我的店铺 → 订单收益 → 订单明细」默认跟随当前店铺，可切换「全部自营店铺」。搜索、状态、套餐及分页与店铺范围一起生效，订单显示所属店铺。全站订单入口保留原有全渠道查询。

迁移 `0069` 根据已有正式自营订单补录客户；后续插入订单或补全订单邮箱时，由同一事务内的触发器自动建立档案。规则如下：

- 按去除首尾空格并转为小写的下单邮箱去重，跨自营店共用同一客户档案。
- 已有直营手工档案优先关联，保留姓名、备注、联系方式、来源和会员记录。
- 未付款的正式下单也计入客户；代理订单、演示订单和支付联调订单不归入自营客户。
- 不根据购买行为虚构会员开通、有效期、姓名或社交联系方式。

「我的客户」支持当前店铺及全部自营店范围；单店范围按实际下单记录筛选。未下单的手工客户可在全部范围查看。页面可见时每 30 秒刷新，返回页面时重新读取。

客户列表、详情及 Excel 包含订单数、已支付订单数、实付、退款、净消费、首次/最近下单时间、店铺及商品。详情展示最近 50 笔订单，汇总包含全部订单。金额从原订单、实际会员现金金额及退款记录动态计算；会员抵扣不算现金收款，手工会员录入金额单独显示。

验证：`node --test tests/owner-order-customers.test.ts`。启用现有 grizzly 本机模拟运行时后，执行 `node scripts/cloudflare/owner-operations-browser.mjs`，使用合成订单验证范围切换、去重、自动刷新、详情、导出和手机布局。

# 自营店订单与自动客户档案

后台显示顺序为 ScholAI、AI星球、备用商店。备用商店保持停用。显示顺序放在店铺设置的 `displayOrder`，原店铺 ID、路径、域名、会员关系与历史订单归属不变。

侧边栏的「订单管理」「退款与售后」「清账统计」「访客统计」各自先选择直营或代理，默认查看直营总览。直营内可切换全部自营店铺或单店，代理页直接查看代理记录。订单与售后按原订单归属查询，退款提醒有对应渠道入口。访客趋势按所选范围去重，时间选项包含北京时间今日。清账汇总、历史周期及明细按渠道查看，原有全站账期通过「记录全站清账」确认窗口操作。

迁移 `0069` 根据已有正式自营订单补录客户；后续插入订单或补全订单邮箱时，由同一事务内的触发器自动建立档案。规则如下：

- 按去除首尾空格并转为小写的下单邮箱去重，跨自营店共用同一客户档案。
- 已有直营手工档案优先关联，保留姓名、备注、联系方式、来源和会员记录。
- 未付款的正式下单也计入客户；代理订单、演示订单和支付联调订单不归入自营客户。
- 订单邮箱用于归档。自动开通记录使用已核验的充值结果、套餐和上游回传的脱敏账号。付款本身不会生成开通日期。

侧边栏「客户管理」可切换直营客户和代理客户。直营支持全部自营及单店，单店按实际下单记录筛选，详情和导出中的订单与自动开通记录也使用该范围。未下单的手工客户可在全部自营中查看。点击客户姓名进入详情。页面可见时每 30 秒刷新，返回页面时重新读取。

`0071` 从已存储的订单与已核验的充值回执读取自动开通历史，每单保留一条。ChatGPT 月度充值按确认开通时间顺延一个北京时间自然月，展示为预计到期，纳入 7 天内到期和已到期筛选。未提供账号或时间时提示待确认；全额退款订单退出到期提醒。自动记录和原有手工开通、续费及升级记录分别展示。导出有自动开通记录时附加相应工作表。

主后台客户列表的订单栏显示实付与最近下单时间。客户详情及 Excel 保留订单数、退款、净消费等明细，详情显示最近 50 笔订单，汇总涵盖全部订单。实付按实际现金金额统计，会员抵扣与手工会员录入金额分别记录。

「优惠情况」按当前店铺范围汇总已付款订单实际使用的自设优惠码、邀新返券和受邀新人优惠。未付款、已取消或已全额退款的订单不计入；返券仅计算已核销金额。`0072` 保存下单时的自设优惠码，可核实的旧订单补录原码，无法核实的历史记录仍显示优惠类别和减免金额。详情可逐单查看用券。

验证：`node --test tests/owner-order-customers.test.ts`。启用现有 grizzly 本机模拟运行时后，执行 `node scripts/cloudflare/owner-operations-browser.mjs`，使用合成订单验证范围切换、去重、自动刷新、详情、导出和手机布局。
